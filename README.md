# SATSam


SATSam is an AI-powered SAT tutor that is meant for underprivileged students wanting higher SAT scores but without the proper tools needed to do so.


## Problem
The main problem SATSam is trying to solve is the inequality when it comes to SAT scores between the rich and the poor. This is due to how richer individuals are able to buy expensive studying materials or tools such as tutors, textbooks, and expensive programs while less fortunate individuals are unable to do so, forcing them to rely on rudimentary or inefficient options.


## Solution
SATSam provides a completely free, efficient SAT studying tool that caters towards an individual needs by finding weak areas, tracking performance, building on strengths, and making targeted studying sessions that improve SAT scores.


## Features
- Personalized study sessions built for the user
- AI explanations of questions
- End of session reviews that go over weak and strong points
- Study plan creator that is based on user circumstance and needs
- Progress tracking
- Pomodoro study timer
- Insights on general user performance
- Settings to change AI model and to configure it for the user's needs


## Possible Future Improvements
- Stronger AI
- Quicker AI responses
- More options for inputting circumstances/user challenges
